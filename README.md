# AnimPipe

Blender pipeline distribution shell plus authored character assets.

- **Frozen pipeline snapshots:** `AnimPipe_gpu_wave_hardened_v3_1.zip`, `blender_training_pipeline_proxy_v1.zip`, and `blender_training_pipeline_proxy_slim.zip` are immutable release archives; do not unpack them in Git.
- **Authored Avery Chen V3:** `assets/`, `scripts/build_avery_chen.py`, and [`docs/characters/avery-chen/README.md`](docs/characters/avery-chen/README.md) are the source of truth for `char.avery_chen` (manifest entry in `assets/assets.yaml`).
- **Patty Patties 2D drop-in:** [`assets/characters/PattyPatties.blend`](assets/characters/PattyPatties.blend) is `char.patty_patties`. Same proxy rig and action names as Avery, illustrated from the style sheet. See [`docs/characters/patty-patties/README.md`](docs/characters/patty-patties/README.md).
